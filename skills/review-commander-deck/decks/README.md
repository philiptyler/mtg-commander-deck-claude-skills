# decks/

Each subdirectory here is one reviewed deck, generated by following
`../SKILL.md`:

- `decklist.txt` — the raw pasted decklist (input)
- `context.json` — decklist quantities merged with Scryfall card data
- `analysis.json` — computed stats and bracket estimate
- `report.md` — the final written review

Nothing in here is hand-written; it's all produced by running the scripts
in `../scripts/` against a decklist.
